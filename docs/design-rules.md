# Правила дизайна fin-web

Обязательны для любого UI-кода (SDUI и общий каркас). Источник истины —
Figma `8RxAFhNubquQ1bz912H2wB` (страница design) и канон токенов
`src/shared/design/tokens.ts`. Нарушения ловятся стражем дрейфа
(`no-hex-drift.test.ts`) и скриншотными тестами (`npm run test:visual`).

## 1. Цвета

- **Только токены.** Литеральные hex/rgb в коде запрещены — страж валит
  сборку. Палитра: `ui-01…08`, `accent-01` (+hover/pressed), `accent-02`
  (+hover), `support-01/02/03`. В tailwind — `bg-ui-01`, `text-accent-02`
  и т.д.; в sx/style — `cssVar(palette.x)` или `cssVar(semantic.x)`.
- **Семантика важнее сырого цвета**: текст — `textPrimary`/`textSecondary`,
  разделители — `divider` (ui-03), зебра — `zebra` (ui-02), выделение —
  `selection` (ui-04), ошибки — `error` (support-01), success —
  `support-02`, warning — `support-03`. Не изобретать роли.
- Цвета с провода (`textColor` ячеек и т.п.) — данные бэка, их не трогаем.
- `pending-*` токены — временные, новые употребления не добавлять.

## 2. Отступы и размеры

- **Шкала 4px**: 4 / 8 / 12 / 16 / 20 / 24 / 32. Произвольных значений нет.
- Вертикальный ритм форм: **16px между полями, 32px между секциями**.
- Гэп между кнопками тулбара — **8px**. Контент страницы — заподлицо с
  тулбаром (боковые отступы задаёт страница/панель, не вложенные стеки).
- Радиусы: **4 / 8 / 12 / 16** (`rounded-sm/md/lg/2xl`). Кнопки и инпуты —
  8; плашка пункта сайдбара — 16; карта контента — 32 (только верхний
  левый угол); панели — 40 слева.
- Высоты контролов: кнопка **40** (small 28–30), инпут **50**
  (инлайн-small **36**), строка таблицы ТЧ по контенту, вкладка **36**,
  пункт меню/опция дропдауна **40**, пункт сайдбара **56**.
- Панель (drawer) — **766px**, паддинги 40 (верх 60 у легаси-эталона).

## 3. Компоненты

- **Кнопки — только `@/shared/ui/buttons` Button.** Сырой MUI `<Button>`
  запрещён. Варианты: `primary` (салатовая, одна на тулбар — главное
  действие), `secondary` (белая), `tertiary` (прозрачная, синий текст;
  icon-only — тёмный глиф). Никаких outlined-рамок и UPPERCASE.
- **Иконки — из реестра Figma** `@/shared/ui/icons` (`figmaIcons`,
  56 глифов, currentColor). Рукодельный SVG — только если глифа нет в
  Figma (фиксировать комментарием).
- Диалог подтверждения — `@/shared/ui/confirm-dialog` (заголовок H2,
  крестик, primary слева). Тосты — `showToast` с ролью, цвета сами.
- Вкладки рабочего стола: актив — голубая `ui-04`, крестики видимы всегда.
- Меню/дропдауны/автокомплиты стилизуются ТЕМОЙ (`theme.ts` overrides), не
  локальными sx.

## 4. Типографика

- Только Google Sans (тема и tailwind уже настроены — не переопределять
  fontFamily локально). Размеры: H2 26/700, H3 20/700, Body1 16/500
  (lh 24), Body2 14/500 (lh 20). В tailwind — `text-h2`… `text-body2`.
- Тексты — через `useTranslation` + `<Typography>` (см. CLAUDE.md).

## 5. SDUI: раскладка принадлежит бэку

- Компоновку задают layout-пропы с провода (`gap`, `size`, `pinBottom`,
  `dividers`, `flex`, `width` — словарь и нормализация: спека
  `docs/superpowers/specs/2026-09-04-sdui-design-constructor-spec.md`).
- Фронт НЕ хардкодит раскладку под конкретный экран. Нужен новый механизм —
  расширяй словарь пропов (спека v2) и договаривайся с бэком, а не пиши
  `if (screen === …)`.

## 6. Проверки перед мержем

1. `npx vitest run` — юниты, включая страж дрейфа и пины стилей.
2. `npm run build`.
3. `npm run test:visual` — скриншотная регрессия (эталоны macOS).
   Намеренное визуальное изменение = `npm run test:visual:update` в том же
   PR с осознанным диффом эталонов; «просто перегенерил, чтобы позеленело» —
   запрещено.
