    Мокап главной. Выберите сотрудника ниже — у каждого профиль доступа КБП и свой шаблон роли. Вверху — организации (только доступные) и период по умолчанию. «Настроить» — перестановка, ширина, ⚙ настройки виджета (в том числе свой период), готовые шаблоны ролей и «Свой виджет». В каталоге только доступные виджеты. Виджеты показывают только готовые данные: отчёты и проверки не формируются на главной, для них есть свои разделы. Настройки сохраняются в этом браузере; цифры демонстрационные.
