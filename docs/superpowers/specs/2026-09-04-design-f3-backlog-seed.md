# Ф3-бэклог (seed из финального ревью Ф1+Ф2, 04.09.2026)

Затравка для аудита Ф3 (спека:
`2026-09-03-design-system-audit-design.md` §2). Это НЕ чек-лист аудита —
только хвосты, найденные ревью ветки `feature/design-system`; чек-лист
строится по общей структуре всех фреймов Figma и вбирает эти пункты.

## Токен-слой

1. `typography` / `radii` / `spacing` из `tokens.ts` никем не потребляются:
   tailwind-конфиг держит собственные литералы fontSize/borderRadius, а
   `fontFamily` продублирован в 4 местах (tokens.ts, tailwind.config.ts,
   `src/app/index.css`, `calendar-layout.tsx`). Схлопнуть к канону.
2. `call-room-dialog.tsx` STAGE_THEME: тёмный фон взят из
   `semantic.textPrimary`, светлый текст из `semantic.divider` — семантика
   инвертирована; при серверной теме фазы 2 перекрасится неверно. Перевести
   на сырые `palette.ui06`/`ui03`.
3. Канонизация оставшихся не-токенов: `text-gray-400` / `bg-amber-100` /
   `bg-gray-400` в calendar-нодах, `GREEN_1C = 'rgb(0,63,47)'`
   (cell-helpers), BACKDROP_BG rgba.
4. MUI `typography.fontFamily` в теме не задан — заголовки (h6 и др.)
   рендерятся Roboto (доветочное состояние). Фикс = намеренное визуальное
   изменение Ф4 с обновлением эталонов.
