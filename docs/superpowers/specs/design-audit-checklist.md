## Кейсы владельца (04.09) → диагноз

1. **«Пятно сбоку страницы»** — тёмная прослойка между пунктами меню и
   светлой картой контента. Геометрия колонки (412/60/20px) совпадает с
   Figma 1:1, «грязной» её делают отклонения самого сайдбара (см. Ш-2…Ш-5:
   иконка-глиф 24px вместо 40px, паддинг 16 вместо 20, радиус 12 вместо
   капсулы) плюс лишнее нижнее скругление карты. Чинится пачкой «Сайдбар».
2. **«Кнопки тулбара — голый MUI»** — подтверждено, П-1/П-2/П-3: в Figma нет
   ни одного outlined-варианта и нет UPPERCASE; primary — салатовая.
3. **«Несуразные отступы на SDUI-страницах»** — системная причина Ф-1:
   SDUI-лейауты берут gap только с провода, дефолт 0px; в Figma жёсткий
   ритм 16/32.
4. **«Мрак в сайдбар-меню»** — пачка «Сайдбар» (Ш-2…Ш-5) + вкладки (Ш-6).

## Пачки Ф4 (порядок фиксов)

Каждая пачка: фикс → полный vitest+build → `test:visual` с осознанным
обновлением эталонов → пункты чек-листа закрываются.

1. **Пачка «Кнопки»** (П-1…П-4): перевод `button-node.tsx` на
   `shared/ui/buttons/button.tsx`, mapping вариантов с провода
   (primary/secondary/tertiary), snap высоты/радиуса/регистра. Закрывает
   кейс владельца №2 одним файлом почти целиком.
2. **Пачка «Ритм форм»** (Ф-1, Ф-2): дефолтный пол гэпов в SDUI-лейаутах
   (16px поля / 32px секции, значения с провода уважаются как override),
   GROUP-отступы. Закрывает кейс №3.
3. **Пачка «Сайдбар и шелл»** (Ш-1…Ш-7): иконки/радиусы/паддинги сайдбара,
   сетка модульной страницы, скругление карты, топбар. Закрывает кейсы №1 и
   №4 (сайдбарная часть).
4. **Пачка «Вкладки»** (Ш-6): состояния workspace-вкладок по компонент-шиту.
5. **Пачка «Токены+тосты+диалоги»** (К-1, Т-1, Т-2): support02/03 в канон,
   тосты по ролям, confirm-диалог SDUI на эталон shared.
6. **Пачка «Меню/автокомплит/панель»** (Т-3, Т-4, Ф-3…Ф-5, К-2).

Ограничения: правки только в SDUI + общий каркас (`shared/`, widgets,
workspace-tabs); легаси-мир руками не полируем (Ф-4/Ф-5 — dict-sidebar —
легаси: чиним точечно ТОЛЬКО если владелец подтвердит, что панель живёт до
сноса легаси достаточно долго). Bit-perfect больше не действует — Ф4 меняет
вид намеренно, каждый фикс с обновлением эталонов в том же коммите.
