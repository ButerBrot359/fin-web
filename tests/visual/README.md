# Визуальная регрессия

- Эталоны рендерятся на macOS (соглашение до появления CI); на других ОС
  тесты не гонять — diff будет ложным.
- `npm run test:visual` — прогон; `npm run test:visual:update` — осознанное
  обновление эталонов (только вместе с визуальным изменением в том же PR).
- Сеть замокана целиком: фикстуры в `fixtures/`, шрифты в `assets/`.
- Фикстуры сняты с dev-api 03.09.2026 живой сессией (тела ответов, без
  токенов); файл = экран, внутри карта «ключ mockApi → ответ». Ключи
  `POST /api/view` различаются по `action.type` и дискриминатору `@`
  (`layoutCode` либо `route`), значение `{ __status, __body }` задаёт
  не-200 ответ (легаси-двери = 422). Правки поверх снятого (out-of-band):
  в `osv-tree.json` state OPEN заполнен датами августа-2026 (стендовая
  форма стартует пустой), в `kartochka-ledger.json` state OPEN заполнен параметрами (счёт 1010, август-2026), даты в COMMAND-ответе
  исправлены на август-2026 (глюк ввода дат на стенде), run снят прямым
  запросом с теми же параметрами.
- Запуск перед мержем в dev обязателен (наравне с build).
- Смоук-эталоны и эталоны экранов создаются test:visual:update; правило:
  обновление эталонов только вместе с осознанным визуальным изменением в
  том же PR.
